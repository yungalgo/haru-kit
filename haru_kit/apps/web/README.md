# Haru web app (haru-kit)

The browser UI of `haru-kit`: characters and language versions, voice library and recorder, `.haru` import/export, shared character registry (**Browse characters**), settings, and the live conversation view (waveforms, subtitles, latency, mute, time remaining, and stereo WAV / TXT / video saving). React + Vite + Tailwind.

Modified from [`higurashi-ai/Haru`](https://github.com/higurashi-ai/Haru) `client/` (see `../UPSTREAM.md`). `haru-kit` ships the built bundle in `haru_kit/static/`, so users do not need Node.js.

## Build

Node 20 or newer. From the repository root:

```bash
scripts/build-web.sh    # runs npm ci + npm run build, and writes haru_kit/static/
```

## Develop

Start `haru-kit` in browser mode (`haru-kit start --on mac --browser` or `--on nvidia`), then in this folder:

```bash
npm ci
npm run dev
```

This serves the client with hot reload and forwards `/api` (HTTP and WebSocket) to `http://localhost:8998`. Set `VITE_HARU_SERVER` in `.env.local` for another address. Microphone access requires a secure context (`localhost` or HTTPS).

## Layout

- `src/pages/Queue/` — setup page: language menu, character library & card editor, shared character registry, voice library & recorder, settings.
- `src/library/` — IndexedDB character/voice library, 24 kHz mono WAV conversion & silence trim, `.haru` ZIP import/export, registry client.
- `src/pages/Conversation/` — live conversation: transports (`hooks/useSocket.ts` for WebSocket, `rtcSocket.ts` for WebRTC with WebSocket fallback), playback, mute, statistics, recording.
- `src/i18n/` — 9-language UI string table (`strings.gen.ts`, generated by `scripts/gen_strings.py`).
- `src/audio-processor.ts` — AudioWorklet that plays the model's audio.
- `src/protocol/` — binary messages of `/api/chat`.
- `public/assets/decoderWorker.min.*` — Ogg/Opus decoder worker of [opus-recorder](https://github.com/chris-rudmin/opus-recorder).
